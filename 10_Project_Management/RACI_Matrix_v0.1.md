# PROJECT RESPONSIBILITY ASSIGNMENT MATRIX (RACI)

## Laboratory Data Governance, Quality and Interoperability Programme

**Version:** 0.1  
**Prepared by:** Harish Mohankumar  
**Project role:** Project Manager / Business Analyst

### 1. Purpose

This RACI matrix defines the proposed responsibilities of key project stakeholders to establish clear ownership, accountability and communication throughout the project.

### 2. Role Abbreviations

- PM/BA: Project Manager / Business Analyst
- ES: Executive Sponsor
- LD: Laboratory Director
- CI: Clinical Informatics Lead
- IT: IT / HIS Manager
- QA: Quality Manager
- DA: Data Analyst
- LT: Laboratory Technologists

### 4. Important Notes

1. The matrix represents proposed responsibility allocation for a hypothetical hospital implementation.
2. The Project Manager / Business Analyst coordinates delivery and maintains documentation.
3. Clinical terminology decisions require appropriate clinical informatics review.
4. Technical feasibility must be reviewed by the IT / HIS team.
5. Final responsibility allocations would be agreed with the actual project sponsor and stakeholders.

### 5. Expected Outcome

The RACI matrix provides clarity regarding who performs, approves, advises on and receives information about each major project activity.

It reduces duplicated work, unclear ownership and delays in decision-making.
