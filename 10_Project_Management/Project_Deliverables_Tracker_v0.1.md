## 3. Status Definitions

| Status | Meaning |
|---|---|
| Not Started | Work has not commenced |
| In Progress | Work is currently underway |
| Under Review | Deliverable is awaiting review |
| Completed | Deliverable has been completed |
| On Hold | Work is temporarily paused |

## 4. Project Progress Monitoring

The Project Manager will:

- Review deliverable status weekly.
- Identify overdue or delayed activities.
- Coordinate with responsible stakeholders.
- Record review feedback.
- Update completion status after verification.
- Escalate delays that affect dependent activities.

## 5. Completion Criteria

A deliverable will be considered complete when:

1. The required content or output has been prepared.
2. The deliverable has been checked for accuracy and completeness.
3. Relevant assumptions and limitations are documented.
4. Required review feedback has been addressed.
5. The final version is stored in the appropriate project folder.
